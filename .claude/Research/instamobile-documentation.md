## Key Setup Steps (from documentation)

### 1. Firebase Console Setup
- Create a Firebase account
- Create a new Firebase project
- Enable required services (Firestore, Auth, Storage, Functions)

### 2. Authentication Setup
- Enable Email/Password authentication
- Enable Phone authentication
- Configure Facebook login
- Configure Apple Sign In

### 3. Firestore Database
- Set up access permissions
- Configure security rules
- Create required indexes

### 4. Firebase Storage
- Enable Storage
- Configure security rules for media uploads

### 5. Cloud Functions
- Install Firebase CLI
- Deploy Node.js functions
- Configure environment variables

### 6. Link to Mobile App
- Download google-services.json (Android)
- Download GoogleService-Info.plist (iOS)
- Configure React Native Firebase packages
